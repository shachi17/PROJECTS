Welcome to my project showcase!

This repository is a collection of **blog-style documentation websites** where I document every project I've built. Instead of just uploading code, I explain the complete journey behind each project—from the idea and planning to the implementation, challenges, and future improvements.

The goal is to create a place where anyone (including future me) can understand **how** and **why** a project was built, not just what the final product looks like.

---

## What You'll Find

Each project has its own dedicated page containing:

- Project overview
- Problem statement
- Architecture & design
- Tech stack used
- Features
- Screenshots & demos 
- Challenges faced
- Things I learned
- Future improvements

Think of it as a developer blog mixed with project documentation.
